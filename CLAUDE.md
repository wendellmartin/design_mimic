# Mimic — scripted FreeCAD build of a life-size FNAF Ruin endoskeleton

Handoff notes for any Claude session (or human) picking this up. Read this first; the
per-version history lives in the Claude memory file `mimic-fnaf-project.md` (Claude Code
project memory), which is longer and more anecdotal.

## What this is

Wendell is building "the Mimic" (the lanky endoskeleton from FNAF: Ruin) as a 7 ft
(TargetHeight 2134 mm) PLA figure printed on a Snapmaker U1 (270 mm cube) in
snap-together pieces. Everything is generated by Python run inside FreeCAD 1.1 headless.
Work so far is a **proof of concept at Scale 0.25 (534 mm)**; life size is `Scale 1`.

Current state: **v1.0** (2026-09-21, tag `v1.0`). Complete figure: detailed head with upper
and lower denture platforms and a separate two-piece **Mouth** (gums+tongue, teeth; multi-material),
shoulder gears, parallel-toed clawed feet, and three limb-segment styles trialled side by side
(**A** strut+rods: left forearm, right shin; **B** two-part piston: right forearm, left humerus,
left femur; **C** bumped pipe: right humerus, right femur, left shin). No hollowing, no version
imprint yet. Assembly stands 533 mm at Scale 0.25 (target 534).

## Design conventions

- **Parameters** live only in `mimic_params.py`. Part files reference them through
  cross-document expressions `Mimic_Resources#Dimensions.X`; `S(name)` = `X * Scale`.
  Numbers inside `add`/`sub` need `mm` (`_q` does it). The part doc must be **saved before**
  any cross-doc expression is set (`new_part_doc` does).
- **Peg/socket snap** is Wendell's own barbed peg (from `Shelf with Rail.FCStd`):
  PegBaseDiameter 3, Flare 3.4, Depth 3, Tolerance 0.2, 35° flank. Peg group is
  **absolute** (not scaled). Derived radii are reproduced to the micron (barb 1.8487, tip
  3.776, socket tip 3.976, cavity 2.0487, lip 1.7487). Faces under `PegMinFace` (9 mm) get
  no pegs and are fused instead. `split_count` chops long struts to fit `BuildVolume`.
- **Frames**: every chained part has origin = centre of its proximal mating face, local +Z
  = chain direction. Sockets proximal, pegs distal. Pelvis is the root. World +Z up, +Y
  forward. Chiral parts: HipBallL/R, ShoulderBallL/R, HandL/R; everything else shared.
- `ball_bend` builds a **full frame** (limb local Y kept on world +Y) so chains have no
  twist — the earlier shortest-arc version yawed the feet 24°.
- Lofted/swept detail (head tubes, denture, toe blades) is **numeric** geometry built at the
  run's scale; change a VarSet value → rebuild to propagate. Primitive-based parts are fully
  expression-linked.

## Wendell's vocabulary (use it back to him)

- Shoulder yoke: **trap** = upper collar (C7 pad), **clavicle** = lower (T1 junction). Pelvis
  collars **L5 / S1 / S5**. Head: **C1** neck junction, **headbar** (the strap), **topbar**,
  **cheekbar**, **jawbar**, **eyeSocket**.
- Shoulder joint: **crest** = the solid sector, **gear** = the spikes on it.
- Feet: **blades** (the three toes), the sole is flat, foot is truncated at its widest point.
- Mouth: the **denture platforms** (U-shaped trays: lower above the jawbar, upper below the
  cheekbar) with **lip** and thin **rods**; the **Mouth** insert = **gums** (domed hump, teeth
  socketed into it, must show beside the molars too) + **tongue** + **teeth** (incisors,
  cuspids, bicuspids, molars; a normal human jaw, not fangs).
- Limb segments: style **A/B/C**; B has **barrels** (square), **pistons** (round rods), a
  **crosshead** with hex nuts; C has **bumps** (rings).
- Feet: the solid **block** ends at the front of the ankle; the **metatarsal** is one loft to
  the toes' combined outline; **web** between the toes; the **claws** stay sharp.

## OCC / FreeCAD lessons (hard-won — don't relearn)

- `Ctx.fuse` tries a MultiFuse, then falls back to a pairwise `Part::Fuse` chain (no Refine)
  when the result is null, invalid, smaller than its largest input, or its bbox doesn't cover
  every input (`_covers`). The pairwise chain warns when a step shrinks. Volume/bbox checks
  are the only reliable failure signal — OCC returns "valid" shapes with bodies missing.
- The first recompute of a long chain can silently drop bodies: `build.py` closes and
  **reopens every part doc** before export.
- **Check exported STLs** with `Mesh.isSolid()` / component count: a valid solid can mesh
  hollow (shoulder ball: sphere face dropped until the sphere's poles were put on the crest axis).
- Coplanar / tangent contacts break fuses (sink bodies 15–60 %, or make the feature part of
  the same sweep profile as the denture lip is). Tori sharing poles need different radii.
- Lofts through collinear circle sections explode; Frenet sweeps need evenly spaced,
  non-collinear points with no inflection (jaw tube uses `Frenet=False`); a spline through a
  long gap then dense points overshoots.
- Head fuses in groups (`Head_G_Frame` = strap+topbars+tubes each fused directly,
  `Head_G_Eyes`), then the denture pieces one at a time (rods first) — pre-fusing the
  denture group made the join fail. Cut tools (sockets, pupils) one at a time.
- `App.Rotation(App.Matrix(...))` needs a **right-handed** column triple; a left-handed one
  silently mirrors (that's how the gear teeth ended up buried in the crest).
- `Part::Wedge` via `_wedge()` (expressions on Xmin..Z2max) is the go-to for tapered blocks.
- `Part::Fillet` on the foot body: select edges by geometry (not in the sole plane), and
  check null/invalid/volume before accepting; fall back to unfilleted.
- Bash heredocs with Python that contains `$` or nested quotes get mangled — write patches
  with the Write/Edit tools or a `python - <<'EOF'` block via FreeCAD's python.exe.
- FreeCADCmd prints progress `(nn %)` with tabs; strip them (`tr -d '\t' | sed ...`).
- A background `until grep ... done` waiter must not filter out its own sentinel line.

## Next steps (as of 2026-09-21, v1.0)

1. **Snap redesign.** The v1.0 barb has 0.0997 mm radial interference taken up by hooping a
   SOLID lip: 5.7 % strain, past PLA's break point, so the first insertion shaves it and the
   joint goes loose. The bore (1.8487) is also sized to the barb, not the shaft (1.5), so the
   peg rattles 0.35 mm. Fix = compliance (split cantilever), bore sized to the shaft, bigger
   and longer peg. Print `JointTest` first and tell Claude which SnapB coupon feels right.
2. Internals and connections (his words): pegs on split faces of style B/C segments land in
   air at life size (no central strut) — needs a split-face plate; hollowing for big pieces.
3. Revisit hands (untouched since v0.2). Version imprint (`Version*` params, not yet applied).
4. Multi-material Mouth: `MouthTeeth.stl` holds 14 shells; per-tooth files if the slicer wants them.
